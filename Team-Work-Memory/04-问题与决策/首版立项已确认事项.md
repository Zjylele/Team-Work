# 首版立项已确认事项

记录日期：2026-11-03，2026-11-05 补充。来源：用户在立项阶段直接确认，并于 2026-11-05 确认执行立项阶段建议。适用范围：第一版。

## 已确认

- 第一版固定一个团队，不做多团队创建或切换。
- 数据库沿用本机已安装的 MySQL 8.0.34，安装位置 `E:\DEVELOP\mysql-8.0.34-winx64`。不再以 MySQL 8.4 LTS 作为当前选型目标。数据库服务是否在运行尚未验证。
- Maven 3.9.14 安装在 `E:\DEVELOP\apache-maven-3.9.14`，命令文件为 `E:\DEVELOP\apache-maven-3.9.14\bin\mvn.cmd`。2026-11-03 已将该 bin 目录加入当前用户 PATH，未改系统级 PATH；新进程执行 `mvn -version` 得到 Apache Maven 3.9.14。
- 使用者可以是工作小组或课程小组，系统不按这两种身份分角色。创建者是最高管理员：邀请成员，创建项目，为每个项目制定阶段，创建任务并指定负责人，维护任务标题、负责人和所属阶段，也可以修改任意任务的状态用来纠正。
- 所有成员可以查看全部项目阶段和全部任务。成员可以开始自己的任务（待开始改为进行中）、结束自己的任务（进行中改为已完成），并补充说明和评论。成员不能把状态改回上一档，也不能新建项目、修改阶段、修改标题或修改负责人。
- 任务状态只有待开始、进行中、已完成，不设待验收。
- 用户先注册并登录。未入团的人看到「创建团队 / 加入团队」；已入团的人进入团队工作台。只能创建一个团队，再次创建会失败。邀请码为 5 位字母加数字，创建者可以查看并重新生成，旧码立即失效。
- 阶段可以改名和调整顺序。阶段下还有任务时不能删除，没有任务时可以删除。项目内可以在看板和列表之间切换。
- 第一版包含团队工作台、项目、任务、通知和个人设置。工作台不统计待验收。负责人收到分配、评论和被创建者改状态；创建者收到成员的开始、完成和评论。自己触发且接收人是自己的通知不发送。
- 个人设置只做显示名、修改密码和退出登录。显示名用于负责人和评论。不做头像、通知偏好和个人简介。
- 任务字段只有标题、说明、负责人、所属阶段、状态。截止日期和优先级不进首版。
- 团队内任何人都可以评论任何任务。
- 创建者可以被指定为负责人。处理自己的任务时只能向前改状态；纠正任意任务状态仍是创建者特权。
- 首版不删除项目、不删除任务、不移出成员、不退出团队。
- 已在团队中的人不能再创建或加入。邀请码错误尝试要限制次数。
- 工作台只放：我负责且未完成的任务、进行中的项目数、最近通知。进行中的项目指至少有一条「进行中」任务的项目。
- 首版不做多团队、待验收、文件上传、WebSocket、Redis、消息队列，以及周期、模块、文档。通知打开页面时拉取。

使用方式的完整记录见 [[01-需求与设计/首版使用范围]]。
