# 成员列表与 SPA 会话

## 已实现

后端补了已入团成员可见的 `GET /api/team/members`。为 Vite 开发服务打开 CORS，`allowCredentials` 为 true。会话 Cookie 和 CSRF Cookie 的路径为 `/`，`SameSite` 仍为 `Lax`，便于同机 `localhost` 不同端口联调。写操作从 `/api/auth/csrf` 取 token 后可以成功。没有做删除项目或任务、多团队、Redis。
