# 前端首版

## 已实现

在 `team-work-frontend` 初始化 Vue 3 + TypeScript + Vite + Element Plus + Vue Router 4 + Pinia。开发代理 `/api` 到 `http://127.0.0.1:8080`，请求 `credentials: include`，写操作先取 `/api/auth/csrf` 再带 header。

已完成页面：注册、登录、未入团创建/加入、工作台（未完成任务、进行中项目数、最近通知）、项目列表、项目详情（默认列表，可切看板）、阶段维护、新建任务、任务详情（说明、评论、负责人开始/结束、创建者纠正状态与标题/负责人/阶段）、通知、个人设置（显示名、密码、退出；创建者可看邀请码并重新生成）。创建者按钮按角色隐藏，权限以后端为准。未做删项目/删任务、退团、头像、文件上传。

负责人选择优先用 `GET /api/team/members`；接口不可用时回退为当前用户与已知用户 ID 输入。

锁定版本见 `package.json`：Vue 3.5.44、Vite 8.3.6、Element Plus 2.14.7、Vue Router 4.6.4、Pinia 4.1.0。pnpm 11.25.0。本次 shell 中 Node 为 `E:\DEVELOP\nodejs` 的 v24.19.0。
