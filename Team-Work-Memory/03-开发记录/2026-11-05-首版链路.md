# 首版链路

## 已确认

同日把立项建议中的范围写入 [[01-需求与设计/首版使用范围]] 和 [[04-问题与决策/首版立项已确认事项]]。个人设置只做显示名、修改密码和退出登录。任务字段不含截止日期和优先级。成员可以补充自己负责任务的说明，不能改标题、负责人或阶段。

## 已实现

后端在 `team-work-backend`。登录使用服务端会话，密码只存哈希。权限在接口内判断。

一条链路已由 `mvn test` 走通：注册并登录、创建团队、用邀请码加入、创建项目和阶段、创建任务、成员补充说明、开始、评论、完成，创建者纠正状态，双方收到对应通知，工作台能看到未完成任务和进行中的项目数。邀请码重新生成后旧码失效，连续错误邀请会受到限制。

空阶段可以删除，阶段下还有任务时不能删除。没有做删除项目、删除任务、移出成员或退出团队。

## 验证

本机 MySQL 8.0.34 服务正在运行。已创建 `teamwork` 与 `teamwork_test`。2026-11-05 在设置 `DB_USERNAME` 和 `DB_PASSWORD` 后执行 `mvn test`，退出码 0。测试连的是 `teamwork_test`。

## 未做

前端尚未初始化。看板和列表切换仍待页面实现；后端已按阶段返回任务，列表接口可供后续页面使用。
