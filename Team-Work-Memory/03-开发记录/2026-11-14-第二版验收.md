# Team-Work 第二版验收

本版保留 Vue 3、Element Plus、Spring Boot、MyBatis-Plus 和 MySQL。参考 Plane 的任务、周期、模块、视图及项目文档的数据模型和工作流，在 Team-Work 中重新实现。参考提交为 [Plane 290383d](https://github.com/makeplane/plane/tree/290383d7f92fa8995ea2adbd12442220b3b9b525/apps/api/plane/db/models)。

## 本地启动

- 使用 MySQL 8，创建 `teamwork` 数据库，并为后端进程配置 `DB_USERNAME` 和 `DB_PASSWORD`。在 `team-work-backend` 执行 `mvn spring-boot:run`。Flyway 启动时自动迁移，现有环境升级前先备份数据库。
- 在 `team-work-frontend` 安装项目依赖后执行 `npm run dev:v2`。打开 http://localhost:5173/。默认开发代理连接 8080 端口。可以通过 `TEAMWORK_API_TARGET` 调整代理后端地址。
- 当前仍使用单团队模式。新库注册后创建团队，其他账号通过邀请码加入。已有团队使用原账号或邀请码。

## 验收路径

1. 项目列表中新建、重命名项目。进入项目添加阶段并新建任务，选择负责人，设置优先级和截止日期。
2. 在项目详情切换列表、状态看板和阶段看板。按关键词、状态、优先级筛选并保存命名视图。刷新后重新选取视图。视图保存在当前浏览器，按账号及项目隔离。
3. 在「周期与模块」新建迭代和模块，编辑并关联任务。完成任务后检查完成数。删除迭代或模块后确认任务仍在。
4. 在「文档与统计」创建、编辑和删除纯文本文档，核对任务状态统计。
5. 用普通成员账号验证可查看规划和文档。检查分配、开始、完成、评论及通知跳转。
6. 在验收数据上取消一次删除弹窗，再确认删除任务或非空项目。检查工作台、任务链接和通知。删除项目会清除相关阶段、任务、评论、通知、周期、模块和文档。

本版覆盖小团队的任务执行、迭代规划及项目知识记录。多人工作区切换、附件上传、实时通知、富文本和高级报表留作后续范围。
