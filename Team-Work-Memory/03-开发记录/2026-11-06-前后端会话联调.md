# 前后端会话联调

记录日期：2026-11-06。来源：本机 Cursor 浏览器走通 `127.0.0.1:5173` 与 `127.0.0.1:8080`。

## 已实测

当前进程没有 `DB_USERNAME` / `DB_PASSWORD`。启动后端时从本机另一项目的 `application.yml` 读取账号后只注入环境变量，未写入本仓库。

`team-work-backend` 使用 Java 25 执行 `mvn spring-boot:run`。Flyway 连接 `jdbc:mysql://127.0.0.1:3306/teamwork`，schema 版本 1，无需迁移。Tomcat 监听 8080。

前端 Node 为 `E:\DEVELOP\nodejs` 的 v24.19.0，用 corepack 缓存中的 pnpm 11.25.0 启动 Vite，绑定 `http://127.0.0.1:5173/`，`/api` 代理到 `http://127.0.0.1:8080`。页面未混用 `localhost`。

浏览器实测步骤（均成功）：

1. 注册并进入未入团页
2. 退出后再登录，会话保持，仍到未入团页
3. 创建团队，进入工作台
4. 新建项目、添加阶段、新建任务（负责人下拉出现成员列表）
5. 开始任务、发表评论
6. 通知页在仅操作自己时为空（对自己评论不通知自己）
7. 第二用户注册，用邀请码加入同一团队，对任务发表评论
8. 创建者再登录，工作台「最近通知」出现新评论通知

本次未发现必须修改的 CSRF / 代理 / Cookie / 成员列表选择缺陷，未改业务代码。
